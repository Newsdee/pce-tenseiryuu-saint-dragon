# Tensiryuu - Saint Dragon SFX patch

Tensenryuu - Saint Dragon is infamous for its obnoxious SFX.

It is so loud that you can barely hear anything else when you fire your weapons.



![Gameplay](screenshots/tenseiryuu_gameplay.png)
![Title Screen](screenshots/tenseiryuu_title.png)

This simple hack disables the weapon fire SFX completely, allowing you to hear the music and enemy explosions.

# How to use this patch
To use this patch, you will need the original ROM file for PC Engine, and use a BPS patcher to apply it.
This will give you a new file that you can use with a Turbo Everdrive for real hardware, or an emulator such as [Mesen2](https://github.com/SourMesen/Mesen2)

You can find an online patcher at [ROMHacking.net](https://www.romhacking.net/patch/).
